# Frontend Development Course

A practical, beginner-friendly repository for learning frontend development through small examples, guided notes, and hands-on practice.

The course starts with HTML structure, adds CSS styling and layout concepts, and then introduces JavaScript programming and browser interaction. Every structured topic includes runnable code, explanations, common mistakes, and practice tasks.

## Course Goals

- Build a strong HTML foundation
- Style pages with organized CSS
- Learn modern JavaScript fundamentals
- Manipulate page content through the DOM
- Respond to user actions with events
- Develop problem-solving skills through exercises and mini-projects

## How to Use This Repository

1. Follow the topics in order.
2. Read the topic README before opening the examples.
3. Open each `index.html` file directly in a browser.
4. Use browser Developer Tools to inspect the page and view the console.
5. Complete the exercises in each `practice-questions.md` file.
6. Change the examples and observe how the output changes.

No package installation or build tool is required for the current lessons. The examples use standard HTML5, CSS3, and modern JavaScript and can be opened locally.
