What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It provides the structure and content of every website you visit.

Basic HTML Structure

Every HTML document has a standard structure:

  • DOCTYPE - Tells browser this is HTML5
  • html - Root element
  • head - Contains metadata
  • body - Contains visible content
