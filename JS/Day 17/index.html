Single-Threaded + Synchronous + Asynchronous JavaScript

1. JavaScript is Single-Threaded

JavaScript has one main execution thread and one main Call Stack. Therefore, JavaScript executes one piece of JavaScript code at a time.

Think of it like a cashier serving one customer at a time.

2. Synchronous Execution

Synchronous means that JavaScript executes statements one after another. The next statement waits until the previous statement finishes.
